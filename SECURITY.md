# Sicherheitslücken melden

Bitte melden Sie Schwachstellen **vertraulich** an **status@integrisec.de** –
nicht über ein öffentliches Issue.

Hilfreich sind: betroffene Datei oder URL, eine kurze Beschreibung und, wenn
möglich, Schritte zum Nachvollziehen.

Sie erhalten innerhalb weniger Werktage eine Rückmeldung. Bitte veröffentlichen
Sie den Fund erst, wenn er behoben ist oder wir uns auf einen Zeitpunkt geeinigt
haben.
